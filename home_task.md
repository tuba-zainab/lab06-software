# Lab 06 Home Task: Snap Package

## Package Name
yq

## Installation Command
```bash
sudo snap install yq
```

## Verification Command
```bash
snap list yq
```

## Purpose
yq is a command-line tool used to read, query, and modify YAML files. YAML is commonly used for configuration files, including Kubernetes configuration files. This tool can help users inspect and manage YAML data from the terminal.

## Conclusion
I searched for the package using Snap, installed it, and verified its installation. This task helped me learn how to find and install additional software using the Snap package manager.
